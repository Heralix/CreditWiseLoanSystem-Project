# CreditWise Loan System

## Project Overview

CreditWise Loan System is a Machine Learning project designed to predict whether a loan application should be **Approved or Rejected** based on an applicant's personal, financial, employment, and credit-related information.

The system is designed to assist a financial institution by analysing historical loan application data and identifying patterns that can support the loan approval process.

## Problem Statement

The traditional loan approval process involves manually evaluating information such as income, employment details, credit history, existing loans, and other applicant information. This process can be time-consuming and may lead to inconsistent decisions.

The objective of this project is to develop a Machine Learning-based system that can analyse applicant information and predict the loan approval outcome.

## Dataset

The dataset contains information about loan applicants, including:

- Applicant Income
- Coapplicant Income
- Employment Status
- Age
- Marital Status
- Dependents
- Credit Score
- Existing Loans
- DTI Ratio
- Savings
- Collateral Value
- Loan Amount
- Loan Term
- Loan Purpose
- Property Area
- Education Level
- Gender
- Employer Category

The target variable is:

**Loan_Approved**
- `1` = Approved
- `0` = Rejected

The original dataset is **not included in this repository** as required by the project instructions.

## Project Workflow

The project includes the following stages:

1. Data loading and exploration
2. Exploratory Data Analysis
3. Data preprocessing
4. Feature preparation
5. Machine Learning model development
6. Model evaluation
7. Loan approval prediction
